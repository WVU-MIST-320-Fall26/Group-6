Earned Value Management (EVM) 
- Project Baseline
  - The project is planned across 3 sprints. By the end of Sprint 2, the team has completed 2/3 planned sprints. The estimated project budget is approximately $250,000 for software development and $200,000 for operating the project during construction. The remaining estimated $300,000-$500,000 is allocated to rolling out the system across all 45 stores. 
- EVM Calculations -

  - Planned value (PV) is the portion of the total project budget that was expected to be completed by the end of Sprint 2.
    - PV= 2/3 X $750,000 - $1,000,000
      - PV = $500,000-$666,666
  - Earned Value (EV) represents the budgeted value of the work actually completed. The team completed 80 out of 98 total estimated story points.
    - Percentage complete = 80/98 = 81.63%
    - EV = 81.63% x $750,000-$1,000,000
        - EV = $612,245-$816,327
  - Actual Cost (AC) represents the assumed cost of the project through the end of Sprint 2.
    - AC = 2/3 x BAC
      - AC = $500,000 - $1,000,000
  - Scheduled Performance Index (SPI) An SPI greater than 1.0 shows that the project is ahead of schedule. The teams SPI of 1.22 shows that is has completed more work than planned by the end of Sprint 2. 
    - SPI = EV / PV
    - SPI = 0.8163 / 0.6667
      - SPI = 1.22
  - Cost Performance Index (CPI) A CPI greater than 1.0 shows favorable cost performance. Based on the AC, the project is recieving more EV than orginially planned. This is based on the assumption that the AC equals 2/3 of the total budget.
    - CPI = EV / AC
    - CPI = 0.8163 / 0.6667
      - CPI = 1.22
